## Why This Matters

### The Problem

Rock Band is a **game**, not a drum simulator. Its pad-to-sound assignments were chosen for **gameplay appeal**, not drum realism:

- Game designers wanted bright colors and clear visuals
- They didn't optimize for ergonomics
- This creates "backwards" muscle memory for real drummers

### Game-Based (Original) vs Realistic (Current)

| Action | Game-Based Feels Like | Realistic Feels Like |
|--------|----------------------|----------------------|
| Hit left pad | Snare (wrong!) | Hi-Hat (correct!) |
| Hit right-top | Hi-Hat (wrong!) | Tom (correct!) |
| Hit right-bottom | Crash (correct!) | Crash (correct!) |

**Realistic mapping:** 4/5 correct (vs 2/5 for game-based)

## Real Drum Kit 101

### Standard Setup

A typical drum kit has this layout (viewed from the drummer's seat):

```
        Kick Pedal (below)
              ↓
              
Left Cymbal          Right Cymbals
(Hi-Hat)            (Crash, Ride)
  ↙                    ↖
  
  ┌──────────────────┐
  │   Drummer        │
  │    Sitting       │
  │    Here          │
  └──────────────────┘
  
  ↖                    ↙
Snare Drum          Floor Tom
(Center)           (Right-Low)
         ↓
    Bass Drum
    (Pedal)
```

### Hand Positions

- **Left Hand**: Plays hi-hat (cymbals on left)
- **Right Hand**: Plays toms (sticks hit toms on right)
- **Both Hands**: Snare (center)
- **Left Foot**: Kick pedal

## Why Realistic Matters for FL Studio

### Music Production Perspective

When recording drums in FL Studio:

1. **Listening Back**: Drums sound in expected positions
   - Hi-Hat on left → sounds "left" in mix
   - Tom on right → sounds "right" in mix
   - Snare center → sounds centered

2. **Visual Consistency**: Matches drum visualization
   - FL Studio shows drum positions visually
   - Your kit layout matches the visual layout
   - Less mental mapping required

3. **Professional Standard**: Matches real drum recordings
   - Professional drummers record with this layout
   - Your recordings match standard drum recordings
   - Easier to mix alongside other drum recordings

## FAQ

### Q: Should I switch to realistic mapping?

**A**: If you:
- ✅ Want to learn real drumming
- ✅ Play drums or want to
- ✅ Record in FL Studio
- ✅ Care about skill transfer

Then **YES**, use realistic mapping (it's already active).

If you:
- ❌ Only want to play Rock Band songs
- ❌ Don't care about real drums
- ❌ Already learned game-based on old system

Then game-based still works, but realistic is better.

---

### Q: Will I get confused switching from game-based?

**A**: Only for 10-15 minutes:

```
Brain Adjustment Timeline:
├─ 0-5 min: "This is different"
├─ 5-15 min: "Wait, this actually makes sense"
├─ 15-30 min: "This feels right now"
└─ 30+ min: "Why would anyone use game-based?"
```

Real drummers adapt **immediately** because it matches their experience.

---

### Q: Does mapping affect MIDI output?

**A**: NO. The mapping only affects which **pad** → which **sound**:

```
Red pad press → Sends MIDI note 42 (Hi-Hat)
                (Was: 38 = Snare in game-based)
                
The MIDI message itself is unchanged.
The drum sound in FL Studio changes.
Your playing technique is unchanged.
```

All 131 tests pass because the mechanism (pad→MIDI) is identical.

---

### Q: Can I switch back to game-based?

**A**: Yes, it's documented in `config/drumMapping.json`:

```json
"modes": {
  "game-based": { "red": 38, ... },
  "realistic": { "red": 42, ... }
}
```

But you won't want to. Realistic is better. 🥁
